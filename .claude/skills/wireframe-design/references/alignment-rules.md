# SVG 对齐计算规则

## 概述

本文档定义了 SVG 线框图中所有元素的对齐规则和计算公式。遵循这些规则可确保：
- ✅ 同行元素垂直对齐一致
- ✅ 文字在容器中垂直居中
- ✅ 列对齐准确无误
- ✅ 间距统一规范

---

## 1. 三大对齐原则

### 原则 1：文字使用 Baseline 对齐
SVG 的 `<text>` 元素的 `y` 属性指定的是**文字基线**（baseline）的位置，而不是文字顶部或中心。

**重要概念：**
- 文字基线：字母底部的假想线（如字母 'A' 的底部）
- 下行字母（如 'g', 'y', 'p'）会延伸到基线以下
- 文字视觉中心 ≈ 基线向上 `0.35 * font_size`

```xml
<!-- 错误：y 属性不是文字中心 -->
<text x="20" y="50">文字</text>  <!-- 基线在 y=50，不是中心 -->

<!-- 正确：使用公式计算基线位置 -->
<text x="20" y="42">文字</text>  <!-- 基线位置经过计算 -->
```

### 原则 2：同行元素必须使用相同的 Y 坐标
在验证码输入框这类同行元素中，所有文字的 `y` 属性必须相同。

```xml
<!-- 错误：输入框和按钮文字 y 坐标不同 -->
<text x="36" y="330">请输入验证码</text>   <!-- 输入框文字 -->
<text x="307.5" y="315">获取验证码</text>  <!-- 按钮文字，高了 15px ❌ -->

<!-- 正确：所有文字使用相同的 y 坐标 -->
<text x="36" y="330">请输入验证码</text>   <!-- 输入框文字 -->
<text x="307.5" y="330">获取验证码</text>  <!-- 按钮文字，对齐 ✓ -->
```

### 原则 3：使用 Transform 而非手动计算
对于复杂对齐，优先使用 SVG 的 `transform` 属性，而非手动计算每个坐标。

```xml
<!-- 推荐：使用 transform 实现居中 -->
<g transform="translate(187.5, 0)">
  <text y="73" text-anchor="middle">标题</text>
</g>

<!-- 可接受：手动计算（适用于简单场景） -->
<text x="187.5" y="73" text-anchor="middle">标题</text>
```

## 2. 垂直对齐公式

### 公式 1：标准字体垂直居中（16px）
**适用场景：** 输入框文字、按钮文字（16px 字体）

```
text_y = container_y + container_height / 2 + font_size * 0.35
```

**示例：输入框文字（容器高度 48px，字体 16px）**
```
text_y = 120 + 48/2 + 16*0.35
       = 120 + 24 + 5.6
       = 149.6 ≈ 150
```

**代码示例：**
```xml
<!-- 输入框起始位置 y=120 -->
<rect x="20" y="120" width="335" height="48"/>
<!-- 文字基线位置 y=150 -->
<text x="36" y="150" font-size="16">请输入内容</text>
```

### 公式 2：小字体垂直居中（12-14px）
**适用场景：** 复选框文字、辅助文字、状态栏文字

```
text_y = container_y + container_height / 2 + font_size * 0.33
```

**示例：复选框文字（容器高度 18px，字体 12px）**
```
text_y = 400 + 18/2 + 12*0.33
       = 400 + 9 + 3.96
       = 412.96 ≈ 413
```

**代码示例：**
```xml
<!-- 复选框起始位置 y=400 -->
<rect x="20" y="400" width="18" height="18"/>
<!-- 文字基线位置 y=413 -->
<text x="46" y="413" font-size="12">记住密码</text>
```

### 公式 3：标签文字对齐
**适用场景：** 表单标签（在输入框上方）

```
label_y = input_y - LABEL_SPACING - LABEL_TEXT_SIZE * 0.33
```

**示例：标签文字（输入框 y=120，字体 14px）**
```
label_y = 120 - 8 - 14*0.33
        = 120 - 8 - 4.62
        = 107.38 ≈ 107
```

**代码示例：**
```xml
<!-- 标签文字 -->
<text x="20" y="107" font-size="14">用户名</text>
<!-- 输入框 -->
<rect x="20" y="120" width="335" height="48"/>
```

**注意：** 在实际使用中，我们通常使用简化方法：
```
label_y = input_y - 8
```
即标签基线位置 = 输入框顶部 - 8px。

### 公式 4：导航栏标题对齐
**适用场景：** iOS 导航栏标题（固定值）

```
title_y = STATUS_BAR_HEIGHT + NAV_BAR_HEIGHT / 2 + FONT_SIZE_H3 * 0.35
        = 44 + 44/2 + 17*0.35
        = 44 + 22 + 5.95
        = 71.95 ≈ 73
```

**代码示例：**
```xml
<!-- 导航栏 -->
<rect x="0" y="44" width="375" height="44"/>
<!-- 标题 -->
<text x="187.5" y="73" font-size="17" text-anchor="middle">页面标题</text>
```

### 公式 5：状态栏文字对齐
**适用场景：** iOS 状态栏文字（固定值）

```
status_text_y = STATUS_BAR_HEIGHT / 2 + FONT_SIZE_CAPTION * 0.35
              = 44/2 + 12*0.35
              = 22 + 4.2
              = 26.2 ≈ 28
```

**代码示例：**
```xml
<!-- 状态栏 -->
<rect x="0" y="0" width="375" height="44"/>
<!-- 时间文字 -->
<text x="20" y="28" font-size="12">9:41</text>
```

## 3. 水平对齐公式

### 公式 6：水平居中
**适用场景：** 按钮文字、导航栏标题

```
center_x = container_width / 2
```

**对于全屏元素（375px 宽）：**
```
center_x = 375 / 2 = 187.5
```

**代码示例：**
```xml
<!-- 导航栏标题水平居中 -->
<text x="187.5" y="73" text-anchor="middle">标题</text>

<!-- 按钮文字水平居中 -->
<text x="187.5" y="430" text-anchor="middle">登录</text>
```

**注意：** 必须设置 `text-anchor="middle"` 才能实现居中。

### 公式 7：内边距定位
**适用场景：** 输入框内文字、按钮内文字

```
text_x = container_x + padding_x
```

**示例：输入框内文字（容器 x=20，内边距 16px）**
```
text_x = 20 + 16 = 36
```

**代码示例：**
```xml
<!-- 输入框 -->
<rect x="20" y="120" width="335" height="48"/>
<!-- 输入框内文字（左边距 16px） -->
<text x="36" y="154">请输入内容</text>
```

### 公式 8：两列布局
**适用场景：** 姓名分栏、地址分栏等

```
col1_x = MARGIN_SCREEN = 20
col1_width = COL_1_WIDTH = 160
col2_x = col1_x + col1_width + COL_GAP = 20 + 160 + 15 = 195
col2_width = COL_2_WIDTH = 160
```

**验证：**
```
col1_width + COL_GAP + col2_width = 160 + 15 + 160 = 335 ✓
```

**代码示例：**
```xml
<!-- 左列 -->
<rect x="20" y="120" width="160" height="48"/>
<text x="36" y="154">姓</text>

<!-- 右列 -->
<rect x="195" y="120" width="160" height="48"/>
<text x="211" y="154">名</text>
```

## 4. 同行元素对齐规则

### 规则 1：验证码输入框和按钮对齐 ⚠️ 关键
**问题：** 这是最容易出错的地方，输入框文字和按钮文字必须使用相同的 Y 坐标。

**正确做法：**
```xml
<!-- 验证码输入框（Y_BASE = 288） -->
<!-- 标签 -->
<text x="20" y="288" font-size="14">验证码</text>

<!-- 输入框 -->
<rect x="20" y="296" width="235" height="48"/>
<!-- 输入框文字（Y 坐标 = 296 + 42 = 338，或直接使用 Y_BASE+42 = 330） -->
<text x="36" y="330" font-size="14" fill="#999">请输入验证码</text>

<!-- 按钮 -->
<rect x="260" y="296" width="95" height="48"/>
<!-- 按钮文字（Y 坐标必须 = 330，与输入框文字相同） -->
<text x="307.5" y="330" font-size="14" text-anchor="middle">获取验证码</text>
```

**关键点：**
- 输入框容器 y = 296
- 按钮容器 y = 296（相同）
- 输入框文字 y = 330
- 按钮文字 y = 330（必须相同）

**错误示例：**
```xml
<!-- ❌ 错误：按钮文字 y 坐标不同 -->
<text x="36" y="330">请输入验证码</text>   <!-- 输入框文字 -->
<text x="307.5" y="315">获取验证码</text>  <!-- 按钮文字，高了 15px -->
```

### 规则 2：复选框和文字对齐
**正确做法：**
```xml
<!-- 复选框起始位置 y=400 -->
<rect x="20" y="400" width="18" height="18"/>
<!-- 文字基线位置 y=400+14=414 -->
<text x="46" y="414" font-size="12">记住密码</text>
```

**计算说明：**
```
text_y = checkbox_y + CHECKBOX_SIZE / 2 + FONT_SIZE * 0.33
       = 400 + 18/2 + 12*0.33
       = 400 + 9 + 3.96
       = 413.96 ≈ 414
```

### 规则 3：图标和文字对齐
**正确做法：**
```xml
<!-- 密码输入框（y=208） -->
<rect x="20" y="208" width="335" height="48"/>
<!-- 密码文字 -->
<text x="36" y="242">••••••••</text>
<!-- 眼睛图标（圆心 y = 208 + 48/2 = 232） -->
<circle cx="330" cy="232" r="8"/>
```

**计算说明：**
- 图标圆心 Y = 容器 Y + 容器高度 / 2
- 图标圆心 Y = 208 + 48/2 = 232

## 5. 垂直间距计算

### 规则 1：标准表单项间距（88px）
**公式：**
```
next_label_y = current_label_y + LABEL_HEIGHT + LABEL_SPACING + INPUT_HEIGHT + SPACING_MD
             = current_label_y + 20 + 8 + 48 + 12
             = current_label_y + 88
```

**示例序列：**
```
第 1 项标签 y = 112
第 2 项标签 y = 112 + 88 = 200
第 3 项标签 y = 200 + 88 = 288
第 4 项标签 y = 288 + 88 = 376
```

**代码示例：**
```xml
<!-- 第 1 项 -->
<text x="20" y="112">用户名</text>
<rect x="20" y="120" width="335" height="48"/>

<!-- 第 2 项（y = 112 + 88 = 200） -->
<text x="20" y="200">密码</text>
<rect x="20" y="208" width="335" height="48"/>

<!-- 第 3 项（y = 200 + 88 = 288） -->
<text x="20" y="288">手机号</text>
<rect x="20" y="296" width="335" height="48"/>
```

### 规则 2：最后一个输入框到按钮的间距
**公式：**
```
button_y = last_input_y + INPUT_HEIGHT + SPACING_LG + SPACING_MD
         = last_input_y + 48 + 24 + 12
         = last_input_y + 84
```

**或使用简化方法：**
```
button_y = last_label_y + 88 + 24
         = last_label_y + 112
```

**示例：**
```xml
<!-- 最后一个输入框（标签 y=288） -->
<text x="20" y="288">手机号</text>
<rect x="20" y="296" width="335" height="48"/>

<!-- 按钮（y = 288 + 112 = 400） -->
<rect x="20" y="400" width="335" height="48"/>
<text x="187.5" y="430">提交</text>
```

## 6. 常见错误和修复

### 错误 1：文字不在容器中心
**错误表现：**
```xml
<!-- 文字看起来偏上或偏下 -->
<rect x="20" y="120" width="335" height="48"/>
<text x="36" y="138">文字偏上</text>  <!-- 错误：没有使用公式 -->
```

**修复方法：**
```xml
<!-- 使用公式计算正确的 Y 坐标 -->
<rect x="20" y="120" width="335" height="48"/>
<text x="36" y="154" font-size="16">文字居中</text>  <!-- 正确：120 + 24 + 5.6 ≈ 150 -->
```

**公式：**
```
text_y = 120 + 48/2 + 16*0.35 = 120 + 24 + 5.6 = 149.6 ≈ 150
```

### 错误 2：同行元素不对齐
**错误表现：**
```xml
<!-- 验证码输入框和按钮文字高度不一致 -->
<text x="36" y="330">请输入验证码</text>   <!-- 输入框文字 -->
<text x="307.5" y="315">获取验证码</text>  <!-- 按钮文字偏高 ❌ -->
```

**修复方法：**
```xml
<!-- 确保同行元素使用相同的 Y 坐标 -->
<text x="36" y="330">请输入验证码</text>   <!-- 输入框文字 -->
<text x="307.5" y="330">获取验证码</text>  <!-- 按钮文字对齐 ✓ -->
```

**检查方法：**
```bash
# 查找同一行中 y 坐标不同的文字
grep -n 'y="[0-9]*"' your-file.svg | grep 'text'
```

### 错误 3：表单间距不一致
**错误表现：**
```xml
<!-- 输入框之间的间距不规范 -->
<text x="20" y="112">用户名</text>
<rect x="20" y="120" width="335" height="48"/>

<text x="20" y="195">密码</text>  <!-- 错误：112 + 83 = 195，不是 88 -->
<rect x="20" y="203" width="335" height="48"/>
```

**修复方法：**
```xml
<!-- 使用标准 88px 间距 -->
<text x="20" y="112">用户名</text>
<rect x="20" y="120" width="335" height="48"/>

<text x="20" y="200">密码</text>  <!-- 正确：112 + 88 = 200 -->
<rect x="20" y="208" width="335" height="48"/>
```

**检查方法：**
- 第一个标签 y 坐标 = 112
- 每个后续标签 y 坐标应该是前一个 + 88
- 序列应该是：112, 200, 288, 376, 464...

### 错误 4：左边距不统一
**错误表现：**
```xml
<!-- 输入框和文字的左边距不一致 -->
<rect x="20" y="120" width="335" height="48"/>
<text x="40" y="154">文字左边距错误</text>  <!-- 错误：40 ≠ 20 + 16 -->
```

**修复方法：**
```xml
<!-- 使用统一的内边距 -->
<rect x="20" y="120" width="335" height="48"/>
<text x="36" y="154">文字左边距正确</text>  <!-- 正确：36 = 20 + 16 -->
```

**公式：**
```
text_x = container_x + INPUT_PADDING_X
       = 20 + 16
       = 36
```

### 错误 5：容器高度不一致
**错误表现：**
```xml
<!-- 输入框高度不统一 -->
<rect x="20" y="120" width="335" height="48"/>  <!-- 正确 -->
<rect x="20" y="208" width="335" height="50"/>  <!-- 错误：高度不一致 -->
```

**修复方法：**
```xml
<!-- 所有输入框使用统一高度 -->
<rect x="20" y="120" width="335" height="48"/>  <!-- 正确 -->
<rect x="20" y="208" width="335" height="48"/>  <!-- 正确 -->
```

**常量：**
```
INPUT_HEIGHT = 48px  （所有输入框）
BTN_HEIGHT = 48px    （所有按钮）
```

## 8. 调试技巧

### 技巧 1：可视化网格
在开发时，可以添加辅助网格来检查对齐：

```xml
<!-- 添加辅助网格（开发时使用，发布前删除） -->
<defs>
  <pattern id="grid" width="10" height="10" patternUnits="userSpaceOnUse">
    <path d="M 10 0 L 0 0 0 10" fill="none" stroke="#f0f0f0" stroke-width="0.5"/>
  </pattern>
</defs>
<rect width="375" height="812" fill="url(#grid)"/>
```

### 技巧 2：检查 Y 坐标
```bash
# 提取所有 y 坐标并排序
grep -oE 'y="[0-9]+"' your-file.svg | sort | uniq -c

# 检查标签 Y 坐标序列（应该是 112, 200, 288...）
grep 'font-size="14"' your-file.svg | grep -oE 'y="[0-9]+"'
```

### 技巧 3：计算器工具
创建一个简单的计算器来验证 Y 坐标：

```javascript
// Y 坐标计算器
const calculateTextY = (containerY, containerHeight, fontSize, fontType = 'standard') => {
  const multiplier = fontSize < 14 ? 0.33 : 0.35;
  return containerY + containerHeight / 2 + fontSize * multiplier;
};

// 示例
console.log(calculateTextY(120, 48, 16)); // 输出: 149.6 (输入框文字)
console.log(calculateTextY(400, 18, 12, 'small')); // 输出: 412.96 (复选框文字)
```
